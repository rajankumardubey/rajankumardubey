# 💫 About Me

I am **Rajan**, a **Computer Engineering student** with a strong interest in **coding and building real-world projects**. I enjoy turning ideas into working systems and prefer learning by **implementing**, not just studying theory.

I actively work on projects to understand the **complete software development process**, including:
- application logic
- data handling
- system flow
- user interaction
- performance and maintainability

Rather than limiting myself to a single area, I aim to build a **strong foundation across all major parts of software development**, so I understand how different components of a system work together.

My goal is to continuously improve my skills through **hands-on coding, project-based learning, and system-level thinking**, and to grow into a well-rounded software engineer.
